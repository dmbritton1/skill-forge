## 2. Rulings made while building E15 (all in the ledger)

1. **Leaky rule examples replaced.** Two examples sat in trap C's domain
   (whitespace, trailing newline). The vocabulary test now bans verdict,
   evidence, quote, wrap, whitespace, verbatim, gate, normalis/normaliz,
   newline, line break, substring and match. *Cost if wrong:* none.
2. **The rule says "do not start a step with 'Find'"**, which matches the
   compliance regex. *Cost if wrong:* the distiller avoids a harmless "Find".
3. **The E13 baseline was unsandboxed and unaudited; the variant drafts will
   be both.** This goes in the write-up as a named caveat, with no code
   change. *Cost if wrong:* an unmeasured difference between the arms, stated
   openly.
4. **A harness failure is not an emission result.** A draw that is
   `session_failed`, errored or missing blocks the probe, and stage B is
   re-run. *Cost if wrong:* a real emission failure that coincides with a
   crash gets re-run.
5. **A draw counts only if its `plugin_commit` mark matches the committed
   variant file's hash.** *Cost if wrong:* none.
6. **Three tightening fixes:**
   - `find_step` looks only in `## Procedure`;
   - `--check-frozen` requires the committed record;
   - `draws` requires a passed smoke.
7. **Parked:** a variant draft that voids mid-round still gets its remaining
   runs. *Cost if wrong:* at most 2 sessions.
8. **Parked:** the allowance probe passing doesn't prove the limit wasn't hit.
   The reader stops the batch after the first refused session. *Cost if wrong:*
   one session.
9. **Parked:** `find_step` needs a bare `## Procedure` heading. The
   duplicated counting predicate in `e15_prep.py` is display-only.

### The criterion (spec §5, pre-registered, do not reinterpret)

V and B:

- **V** is resolved ÷ valid runs, pooled over the non-void delivered variant
  drafts.
- **B** is the same over the three baseline drafts.
- **d** = V − B.

| result | reading | shipped `skills/distilling-skills/SKILL.md` |
| --- | --- | --- |
| d ≥ +0.40 **and** V ≥ 0.50 | **the rules help** | change it (Step 6) |
| −0.15 ≤ d ≤ +0.15 | no large effect | unchanged |
| any other d > −0.40 | ambiguous | unchanged |
| d ≤ −0.40 | the rules hurt | unchanged |
| < 3 variant drafts delivered | emission | unchanged, no probe |
